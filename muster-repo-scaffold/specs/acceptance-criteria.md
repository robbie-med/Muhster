# MVP Acceptance Criteria

- Church can run MUSTER locally.
- Church can import or create households.
- Each household can be assigned to a deacon and zone.
- Each household can list resources.
- Each household can make commitments.
- Deacons can create, verify, assign, and manage needs.
- Verified needs can become care cases.
- Deacons can log interventions and follow-up.
- Lead deacon can run weekly muster review.
- Threats can be logged, scored, assigned, and reviewed.
- Disaster readiness can be tracked per household.
- Property work orders can be created, assigned, and closed.
- Assets can be inventoried.
- Reports can be exported.
- Sensitive records are permission-controlled.
- Audit logs show sensitive record access.
- Backups can be generated and restored.
