# Build Plan

## Milestone 1: Local desktop foundation

Authentication shell, roles, permissions, audit logs, app layout, local repository, seed data, backup/restore concept.

## Milestone 2: Household and resource core

Household roster, zones, assigned deacons, resource muster, CSV import/export.

## Milestone 3: Commitments and needs

Commitment ledger, needs intake, need verification, initial case creation.

## Milestone 4: Care operations

Care cases, operation plans, intervention log, follow-ups, blockers.

## Milestone 5: Operations Board and reports

Operational metrics, weekly muster brief, elder report, readiness report.

## Milestone 6: Household app

Check-in, report need, resources, commitments, secure message thread.

## Milestone 7: E2EE

Device identity, thread keys, encrypted messages, encrypted attachments, device revoke.

## Milestone 8: Disaster readiness and Disaster Mode

Profiles, check-ins, unknown households, physical checks, disaster brief.

## Milestone 9: Threats, property, and assets

Threat registry, work orders, preventive maintenance, asset inventory.

## Milestone 10: Field apps

Visit and Disaster first. Work Crew, Meals, Security, Transport, Inventory later.
